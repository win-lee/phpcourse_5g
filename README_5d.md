# phpcourse_5d

Interaktive Lernwebsite für den PHP-Unterricht der 5D – angepasst an die Unterrichtsdateien der Klasse (01_first.php … 11_zufallszahlen.php) und die Übungsaufgaben UE_01 Blog, UE_02 Einmaleins Basic, UE_3a Einmaleins-Nachbau (Vorlage tabelle.html), UE_3 Einmaleins Extended, Quadratkarten (2 Schritte) und UE_04 Zahlenraten.

Lernpfad mit 11 Kapiteln + Lern-Beispiel, Spickzettel, Übungen mit aufklappbaren Lösungen und Quiz (16 Fragen) mit persönlichem Fortschritt (lokal im Browser gespeichert).
