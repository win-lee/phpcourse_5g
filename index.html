💻 Die Nummern entsprechen unseren Unterrichtsdateien (01–12)

PHP läuft auf dem Server und erzeugt HTML, das im Browser ankommt. Während HTML nur statisch ist (jeder sieht dasselbe), kann PHP Inhalte dynamisch berechnen. Die Themen hier folgen genau unseren Unterrichtsdateien 01_helloworld.php bis 11_zufallszahlen.php – plus den drei Cookie-Dateien im Ordner 12_cookies

Dein PHP-Skript beginnt mit <?php – ab hier wird Code ausgeführt. Mit echo gibst du Text aus, und mit Kommentaren dokumentierst du dein Programm für dich und andere.

01_helloworld.php
<!-- HTML Kommentar -->
<?php
// 01_helloworld.php

// einzeiliger Kommentar

/*
mehrzeiliger
Kommentar
*/

// Ausgabe in PHP
echo "Hello World!";
echo "<br>";
echo "Jippie..";

?>

🔍 Was du hier lernst

  • echo gibt alles aus, was in den Anführungszeichen steht
  • HTML-Tags funktionieren im String: "<br>" erzeugt einen echten Zeilenumbruch im Browser
  • Es gibt zwei Kommentar-Arten: <!-- HTML-Kommentar --> gilt für die ganze Datei, // und /* */ nur innerhalb des PHP-Blocks
Merke dir: Jede Anweisung endet mit einem Semikolon (;). Vergisst du es, gibt PHP einen Parse Error – der häufigste Anfängerfehler!
✏️ Deine Aufgabe: Erstelle eine Datei 01_helloworld.php und gib deinen eigenen Namen mit echo aus – einmal normal und einmal fett.

PHP lebt mitten im HTML: Überall, wo dynamischer Inhalt gebraucht wird, öffnest du kurz den PHP-Block, gibst etwas aus – und der Browser bekommt fertiges HTML.

02_html.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML & PHP</title>
</head>
<body>
    <h1>Willkommen <?php echo "Gertrud"; ?></h1>
    <p><?php echo "Ich bin ein <b>Absatztext</b>...";?></p>
</body>
</html>

🔍 Was du hier lernst

  • <?php ... ?> kann beliebig oft mitten im HTML geöffnet und geschlossen werden
  • Der Browser sieht nur das Ergebnis – im Seitenquelltext steht kein PHP mehr
  • Auch HTML-Tags wie <b>...</b> dürfen im echo-String stehen
Merke dir: Der Server ersetzt die PHP-Blöcke durch ihre Ausgabe – dann erst wird die Seite an den Browser geschickt. Im Browser angekommen ist alles nur noch HTML.
✏️ Deine Aufgabe: Baue eine eigene Seite 02_html.php mit Überschrift, Absatz und deinem Namen per echo im HTML.

Variablen speichern Werte, die du später wieder verwenden oder verändern kannst. Jede Variable beginnt mit einem $-Zeichen.

03_variablen.php
<?php
// 03_variablen.php

// Variablen in PHP beginnen mit $

$text = "Hallo PHP"; // string
$zahl = 5; // integer
$komma = 4.5; // float
$boolean = true; // boolean

// Ausgabe einer Variable einfach im echo
echo "Die Variable zahl hat den Wert $zahl";

// geht aber auch mit Verknuepfung (Punkt)
echo "<br>Die Variable text hat den Wert: ".$text;
?>

🔍 Was du hier lernst

  • Die Datentypen: string (Text), integer (ganze Zahl), float (Kommazahl mit Punkt: 4.5!), boolean (true/false)
  • Zwei Wege der Ausgabe: die Variable direkt in den String einbetten ("Wert $zahl") oder mit Punkt verknüpfen ("Wert: ".$text)
Merke dir: Kommazahlen schreibt man mit Punkt: $komma = 4.5; – nicht 4,5. Mit Komma gibt es eine Fehlermeldung!
✏️ Deine Aufgabe: Lege Variablen für deinen Namen und dein Geburtsjahr an und gib einen schönen Begrüßungssatz aus – einmal eingebettet, einmal mit Punkt verknüpft.

Möchtest du etwas 10-mal wiederholen? Schreibst du 10 Zeilen? Nein – dafür gibt es die for-Schleife. Sie hat genau drei Parameter:

04_schleife.php
<?php
// 04_schleife.php

// FOR Schleife
// 1. Parameter: Startwert (wo zaehlt die Schleife los?)
// 2. Parameter: Abbruchbedingung (wann hoert die Schleife auf?)
// 3. Parameter: Schrittweite (wie zaehlt die Schleife weiter?)
for ($i=1; $i<=10; $i++) {
    echo "FOR Schleife... $i";
    echo "<br>";
}

?>

🔍 Die drei Parameter im Detail

  • Startwert: $i=1 – die Zählvariable beginnt bei 1
  • Abbruchbedingung: $i<=10 – läuft, solange $i kleiner oder gleich 10 ist
  • Schrittweite: $i++ – erhöht $i nach jedem Durchlauf um 1
Merke dir: $i++ ist die Kurzform von $i = $i + 1. Die Variable $i nennt man Iterator oder Zählvariable.
✏️ Deine Aufgabe: Schreibe eine Schleife, die von 1 bis 20 zählt. Tipp: Nur die Abbruchbedingung ändern!

Lern-Beispiel aus dem Unterricht (abfrage-schleife.php): 26 Blöcke mit Überschrift und Text – und nach jedem zweiten Block soll ein zusätzliches <hr> ausgegeben werden. Dafür kombinieren wir erstmals Schleife + Abfrage – und lernen dabei den Modulo-Operator kennen.

abfrage-schleife.php – die flexible Variante
for ($i=1; $i<=26; $i++) {
    echo "<b>Überschrift vom Block $i</b>
    <br>
    <em>Ich bin ein Text vom Block</em>
    <hr>";

    // nach jedem zweiten Block ein <hr> zusätzlich ausgeben
    // Lösungsvariante 2 (eher flexibel)
    // Modulo (%-Zeichen) ergibt den Rest einer Division
    if ($i % 2 == 0) {
        echo "<hr>";
    }
}

Im Unterricht haben wir auch die Variante 1 besprochen: für jede gerade Zahl eine eigene if-Abfrage (if ($i==2) ... if ($i==4) ... if ($i==6) ...) – das funktioniert, ist aber „nicht sehr flexibel“: Bei 26 Blöcken bräuchtest du 13 Abfragen, und bei jeder Änderung der Blockzahl müsstest du alle anpassen.

Merke dir: $i % 2 ist der Modulo-Operator – er liefert den Rest der Division. Gerade Zahlen haben Rest 0, ungerade Rest 1. Mit einer einzigen if-Abfrage regelst du alle Fälle – dieselbe Technik wie bei den Quadratkarten und in Lektion 06!

Jetzt kombinieren wir alles: Die Schleife läuft auf dem Server und erzeugt HTML – aus 3 Zeilen PHP wird eine Liste mit 12 Einträgen!

05_htmlschleife.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Schleife</title>
</head>
<body>
    <h1>HTML Schleife</h1>
    <ul>
    <?php
        for ($mimi=1; $mimi<=12; $mimi++) {
            echo "<li>Mimimimi</li>";
        }
    ?>
    </ul>
</body>
</html>

🔍 Was hier passiert (Schritt für Schritt)

  • Der Browser lädt die Seite → der Server führt den PHP-Block zwischen <?php und ?> aus
  • Die Schleife läuft 12-mal und erzeugt jedes Mal ein <li>-Element
  • Der Browser erhält am Ende 12 fertige Listeneinträge – ohne dass wir 12 Zeilen tippen
  • Die Zählvariable muss nicht $i heißen – hier heißt sie $mimi. Der Name ist egal, gezählt wird genauso!
Merke dir: Das ist das Grundprinzip dynamischer Webseiten: PHP erzeugt HTML – aus Daten, aus Berechnungen, aus Schleifen. Statt 20 Zeilen tippen: 3 Zeilen PHP!
✏️ Deine Aufgabe: Lasse die Schleife von 1 bis 20 laufen und nummeriere die Einträge: "<li>Besucher Nr. $mimi</li>".

Dein Programm soll entscheiden können – je nach Wert einer Variable. Dafür gibt es die Abfrage (auch Verzweigung genannt) mit if, else if und else.

06_abfrage.php
<?php
// 06_abfrage.php

$alter = 18;

if ($alter < 16) {
    echo "Nein, du bleibst draußen.";
}
else if ($alter <= 18) {
    echo "Du darfst rein, aber keine harten Drinks";
}
else if ($alter == 20) {
    echo "Willkommens-Shot inklusive";
}
else {
    echo "Ja, komm rein.";
}

?>

🔍 Was du hier lernst

  • PHP prüft die Bedingungen von oben nach unten – die erste wahre Bedingung gewinnt, der Rest wird übersprungen
  • Mit $alter = 18: 18 < 16 ist falsch → weiter; 18 <= 18 ist wahr → Ausgabe „Du darfst rein, aber keine harten Drinks“
  • else ist der Notausgang: es greift, wenn keine Bedingung stimmt
Merke dir: Die Reihenfolge ist entscheidend! Prüfe immer von eng nach weit – hier ist das schon eingebaut: erst < 16, dann <= 18, dann == 20. Schreibst du umgekehrt zuerst <= 18, würde die 16-Jahrige nie „draußen“ bleiben.
✏️ Deine Aufgabe: Schreibe eine Noten-Abfrage: Bei einer Variable $note soll „Sehr gut“ (1), „Gut“ (2), „Bestanden“ (3–4) oder „Nicht bestanden“ (5–6) ausgegeben werden.

Jetzt wird es spannend: Die Benutzer:in gibt etwas ein – und dein PHP-Skript reagiert darauf. Das HTML-Formular schickt seine Daten an denselben Server, der sie in der Superglobalen $_POST ablegt.

07_formular.php
<form method="post">
    <input name="eingabe" placeholder="Gib was ein">
    <input name="alter" placeholder="Alter" type="number">
    <button>Send it!</button>
</form>

<?php
// Ein Formular "auslesen"
// Formularmethode: post

if ($_POST) { // nur wenn ueberhaupt ein Formular abgeschickt wurde

    echo $_POST["eingabe"];
    echo "<br>";

    if ($_POST["alter"]) { // ueberpruefen, ob das Feld ausgefuellt wurde
        echo $_POST["alter"];
    }
    else {
        echo "kein Alter angegeben";
    }
}
?>

🔍 Was du hier lernst

  • Jedes <input> mit einem name-Attribut landet nach dem Abschicken in $_POST["name"]
  • if ($_POST) ist die Kurzprüfung „wurde überhaupt ein Formular abgeschickt?“ – beim ersten Seitenaufruf ist das noch nicht der Fall!
  • Verschachtelte Abfragen: Innerhalb des if ($_POST) prüft ein zweites if ($_POST["alter"]), ob das Feld überhaupt ausgefüllt wurde – sonst kommt „kein Alter angegeben“
  • method="post" im Formular legt fest: die Daten reisen unsichtbar im Request
Merke dir: Formular und PHP stehen in derselben Datei – die Seite schickt die Daten an sich selbst. Beim allerersten Aufruf ist $_POST noch leer, erst nach dem Klick auf „Send it!“ sind die Daten da.
✏️ Deine Aufgabe: Erweitere das Formular um ein Feld für „Wohnort“ und gib einen vollständigen Satz aus, z. B. „Du heißt ..., bist ... Jahre alt und wohnst in ...“.

Derselbe Ablauf wie in Lektion 07 – nur mit method="get". Der wichtigste Unterschied: Bei GET landen die Eingaben sichtbar in der URL.

08_formular-get.php
<form method="get">
    <input name="eingabe" placeholder="Gib was ein">
    <input name="alter" placeholder="Alter" type="number">
    <button>Send it!</button>
</form>

<?php
// Ein Formular "auslesen"
// Formularmethode: get

echo $_GET["eingabe"];
echo "<br>";
echo $_GET["alter"];

?>

Nach dem Abschicken ("Send it!") sieht die Adressleiste so aus:

URL nach dem Abschicken
.../08_formular-get.php?eingabe=Hallo&alter=17

🔍 GET oder POST – wann was?

  • GET: Daten stehen in der URL – gut für Suchen und Filter, man kann die Seite verlinken und als Lesezeichen speichern. Nicht für Passwörter!
  • POST: Daten reisen unsichtbar im Request – gut für Passwörter und sensible Angaben
  • In PHP liest du GET-Daten mit $_GET["eingabe"] statt $_POST["eingabe"] aus – sonst gäbe es eine Fehlermeldung
Merke dir: In der URL erkennst du GET-Formulare am Fragezeichen: alles dahinter sind Name-Wert-Paare, getrennt durch &. Ruf die URL doch mal direkt mit eigenen Werten auf – ganz ohne Formular!
✏️ Deine Aufgabe: Ändere dein Noten-Abfrage-Programm: Die Note soll über ein GET-Formular eingegeben werden und die Ausgabe erscheint darunter.

Jetzt bauen wir alles zusammen: ein vollständiges HTML-Dokument mit Formular – und eine saubere Prüfung, ob überhaupt etwas gesendet wurde. Dafür sorgt isset().

09_formular-html.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Formular mit HTML</title>
</head>
<body>
    <h1>E-Mail check</h1>
    <form method="post">
        <input name="email" type="email" placeholder="E-Mail">
        <button type="submit">Überprüfen</button>
    </form>
    <p>
    <?php
        if ( isset($_POST["email"]) ) {
            $email = $_POST["email"];
            echo "Deine E-Mail $email ist gueltig";
        }
    ?>
    </p>
</body>
</html>

🔍 Was du hier lernst

  • isset($_POST["email"]) prüft: Existiert dieses Feld – wurde es also abgeschickt? So vermeidest du Warnungen beim ersten Seitenaufruf
  • type="email" lässt den Browser selbst prüfen, ob eine gültige E-Mail-Adresse eingegeben wurde
  • Die Ausgabe steht genau dort im HTML, wo der PHP-Block ist – hier im <p>-Element
Merke dir: Das ist das professionelle Muster für fast jede Formular-Seite: Formular oben, if (isset(...)) darunter – erst prüfen, dann verarbeiten.
✏️ Deine Aufgabe: Baue einen „Login-Check“: Felder für Benutzername und Passwort (POST!). Mit isset() prüfst du, ob beide abgeschickt wurden – wenn ja: „Willkommen!“

Ein echtes Formular hat mehr als ein Textfeld: Radio-Buttons für Auswahlmöglichkeiten – und nach dem Abschicken bleiben die Eingaben dank PHP-Prefill erhalten.

10_formular-prefill.php
<?php
// 10_formular-prefill.php

if ($_POST) { // <- prüft, ob ein Formular abgeschickt ist
    $eingabe = $_POST["eingabe"];
    echo "Deine Eingabe: $eingabe";

    $hobby = $_POST["hobby"];
    echo "<br>Dein Hobby: $hobby";
}
?>

<form method="post">
    <input name="eingabe" placeholder="Gib was ein" value="<?php echo $eingabe;?>">

    <input type="radio" name="hobby" value="Reiten">Reiten
    <input type="radio" name="hobby" value="Turnen">Turnen

    <button>Abschicken</button>
</form>

🔍 Was du hier lernst

  • if ($_POST) ist die Kurzform von „wurde irgendwas per POST geschickt?“ – wie isset() in Lektion 09, nur kürzer
  • Prefill: value="<?php echo $eingabe;?>" schreibt die alte Eingabe zurück ins Feld – der Name bleibt nach dem Abschicken stehen
  • Radio-Buttons mit gleichem name bilden eine Gruppe – nur eine Option wählbar, ihr value landet in $_POST["hobby"]
Merke dir: Das name-Attribut entscheidet alles: gleiches name = gleiche Gruppe (Radio), und unter genau diesem name findest du den Wert in $_POST.
✏️ Deine Aufgabe: Ergänze eine eigene Radio-Gruppe (z. B. Lieblingsfach) und fülle das Textfeld nach dem Abschicken wieder vor.

Mit rand() erzeugt PHP Zufallszahlen – die Basis für Spiele, Zufallsbilder und Überraschungen auf der Webseite.

11_zufallszahlen.php
<?php
// 11_zufallszahlen.php

// Zufallszahlen in PHP mit rand(MIN, MAX)

$zuza1 = rand();
echo "Zufallszahl1: $zuza1";
echo "<br>";

$zuza2 = rand(1, 100);
echo "Zufallszahl2: $zuza2";

?>

🔍 Was du hier lernst

  • rand() ohne Parameter: eine große, beliebige Zufallszahl
  • rand(1, 100): eine Zufallszahl zwischen 1 und 100 (beide Grenzen sind erlaubt)
  • Bei jedem Seitenaufruf kommt eine neue Zahl – genau so funktioniert das Zahlenraten weiter unten!
Merke dir: rand(MIN, MAX) liefert eine ganze Zufallszahl inklusive beider Grenzen – ein Würfel wäre rand(1, 6).
✏️ Deine Aufgabe: Simuliere einen Würfel: Gib bei jedem Aufruf eine zufällige Zahl von 1 bis 6 aus.

Neu im Unterricht: Cookies! Ein Cookie ist eine kleine Information, die PHP im Browser der Besucherin speichert – und die bei jedem weiteren Seitenaufruf automatisch mitgeschickt wird. Damit kann sich eine Seite an dich „erinnern“. Die drei Dateien liegen bei uns im Ordner 12_cookies.

Schritt 1 – ein Cookie setzen (cookies_1.php):

12_cookies/cookies_1.php
<?php
// cookies_1.php

// Cookie erstellen ("setzen"): 3 Parameter
// 1. Parameter: Name des Cookies
// 2. Parameter: Wert des Cookies
// 3. Parameter: Ablaufdatum - aktuelle Zeit PLUS Sekunden

setcookie("username", "sepp", time()+45 );

echo "Cookie wurde erzeugt";

?>

Schritt 2 – ein Cookie auslesen (cookies_2.php) – lade die Seite danach mehrmals neu:

12_cookies/cookies_2.php
<?php
// cookies_2.php

// Cookie auslesen (gibt es ein bestimmtes Cookie?)
// Prüfen ob ein Cookie existiert: isset

if ( isset($_COOKIE["username"]) ) {
    echo $_COOKIE["username"];
}
else {
    echo "Kein Cookie username gefunden.";
}

?>

Schritt 3 – ein Cookie löschen (cookies_3.php):

12_cookies/cookies_3.php
<?php
// cookies_3.php

// Cookie wieder löschen
// man verwendet wieder setcookie mit folgenden Parametern
// 1. Parameter: Name des Cookie
// 2. Parameter: LEER lassen
// 3. Parameter: Zeit in Vergangenheit

setcookie("username", "", time()-100);

echo "Cookie gelöscht";
?>

🔍 Was du hier lernst

  • setcookie(NAME, WERT, time()+SEKUNDEN) setzt ein Cookie – mit Name, Wert und Ablaufzeit
  • Auslesen wie bei Formularen über die Superglobale $_COOKIE["name"] – vorhanden? Das prüfst du mit isset() (Lektion 09!)
  • Löschen geht wieder mit setcookie(): leerer Wert + Zeit in der Vergangenheit (time()-100)
  • Cookies sind überlebensnotwendig für Logins, Warenkörbe – und die Übungen besuchszaehler.php und UE_09 Lieblingsfarbe weiter unten
Merke dir: Das Ablaufdatum ist aktuelle Zeit PLUS Sekunden: time()+45 heißt „gilt 45 Sekunden“ (cookies_1.php), time()+120 „gilt 2 Minuten“ (besuchszaehler & Lieblingsfarbe). Nach dem Ablaufdatum löscht der Browser das Cookie von selbst.
✏️ Deine Aufgabe: Probiere es aus: Führe cookies_1.php aus, dann sofort cookies_2.php – und danach noch einmal nach einer Minute. Was zeigt cookies_2.php an, wenn das Cookie (45 Sekunden!) abgelaufen ist?

Aufgabe (PHP_UE1b_Shop_1.php): Gib mit einer Schleife 12 Produktkarten aus. Jede Karte hat: Produktnamen fortlaufend nummeriert („Produkt 1“ …), einen Preis, der aus der Zählvariable berechnet wird (Preis = Nummer × 5 €), und einen Button „In den Warenkorb“. Gestalte die Karten mit CSS (Rahmen, Abstand, display: inline-block oder flex).

Tipp: Innerhalb der Schleife rechnen: $preis = $i * 5; – dann beides im echo ausgeben.
Shop Teil 1 – Kernidee
for ($i=1; $i<=12; $i++) {
    $preis = $i * 5;
    echo "<div class='card'><h3>Produkt $i</h3>
          <p>$preis €</p>

}

Aufgabe (PHP_UE1b_Shop_2.php): Je nach Produktnummer bekommt jede Karte ein Label und eine CSS-Klasse: Produkt 1–4: „Günstig“ (Klasse guenstig), 5–8: „Standard“ (standard), 9–12: „Premium“ (premium). Zusatz: Produkt 12 zeigt zusätzlich „Bestseller!“. Die drei Klassen unterscheiden sich optisch deutlich (z. B. grüner, grauer, goldener Rahmen).

Tipp: Erst mit if/else if/else die Variable $klasse und $label festlegen – dann die Karte ausgeben. Das hält den echo-Befehl sauber.
Shop Teil 2 – Kernidee
for ($i=1; $i<=12; $i++) {
    if ($i <= 4) { $klasse = "guenstig"; $label = "Günstig"; }

Übung UE_09 (lieblingsfarbe.php): Deine Seite soll sich an die gewählte Lieblingsfarbe erinnern. Öffne die Startdatei lieblingsfarbe.php – vorhanden sind schon das Formular mit dem Farbfeld (type="color") und die Variable $farbe. Arbeite nur im Bereich ganz oben in der Datei.

🔍 Die drei Fälle laut Angabe

  • Fall 1: Die Seite wird nach der Formulareingabe neu geladen → die Farbwahl aus $_POST soll als Hintergrundfarbe angezeigt und im Cookie gespeichert werden
  • Fall 2: Seite wird ohne Formulareingabe geladen, aber es existiert schon ein Cookie von einem früheren Besuch → Farbe aus dem Cookie anzeigen
  • Fall 3: Aller erster Besuch – kein Formular, kein Cookie → Hintergrundfarbe bleibt weiß
Merke dir: Hinweise laut Angabe: Es muss nur in dieser einen Datei gearbeitet werden. Das Cookie läuft nach zwei Minuten ab – teste danach, ob deine Seite wieder weiß wird!

Musterbeispiel (nur Schulnetz): webserver.ferrarischule.at/beispiele/ue_lieblingsfarbe/lieblingsfarbe.php

lieblingsfarbe.php – die drei Fälle im PHP-Block
<?php

$farbe = "white";

if ( isset($_POST["farbwahl"]) ) {
    // Fall 1: Formular wurde abgeschickt
    $farbe = $_POST["farbwahl"];
    setcookie("farbwahl", $farbe, time()+120);   // 2 Minuten
}
elseif ( isset($_COOKIE["farbwahl"]) ) {
    // Fall 2: Cookie von einem frueheren Besuch
    $farbe = $_COOKIE["farbwahl"];
}
// Fall 3: weder noch -> $farbe bleibt "white"

?>
<!doctype html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Lieblingsfarbe</title>
        <style>
            body { background-color: <?php echo $farbe ?> ; }
            h1 { background-color: turquoise; color: yellow; }
        </style>
    </head>
    <body>
        <h1>Waehle deine Lieblingsfarbe</h1>
        <form method="POST">
            <input type="color" name="farbwahl">
            <br>
            <input type="submit">
        </form>
    </body>
</html>
