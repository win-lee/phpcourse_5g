Hier lernst du Schritt für Schritt, wie du mit PHP dynamische Webseiten erstellst – von der ersten Ausgabe bis zur eigenen Schleife im HTML. Klicke auf ein Thema, um loszulegen!

💻 Die Nummern entsprechen unseren Unterrichtsdateien (01–12)

PHP läuft auf dem Server und erzeugt HTML, das im Browser ankommt. Während HTML nur statisch ist (jeder sieht dasselbe), kann PHP Inhalte dynamisch berechnen. Die Themen hier folgen genau unseren Unterrichtsdateien 01_first.php bis 11_zufallszahlen.php – plus den beiden Dateien im Ordner 12_formular-action. Schau sie dir parallel an!

Dein PHP-Skript beginnt mit <?php – ab hier wird Code ausgeführt. Mit echo gibst du Text aus, und mit Kommentaren dokumentierst du dein Programm für dich und andere.

01_first.php
<?php
// PHP wird durch <?php gekennzeichnet
/*
mehrzeiliger
Kommentar
*/

// Ausgabe in PHP mit echo
echo "Hello <b>World!</b>"; // am Ende immer ;
echo "<br>";
echo "Juhu";

?>

🔍 Was du hier lernst

  • echo gibt alles aus, was in den Anführungszeichen steht
  • HTML-Tags funktionieren im String: "Hello <b>World!</b>" erscheint fett im Browser
  • // für einzeilige Kommentare, /* ... */ für mehrzeilige – der Server ignoriert sie
Merke dir: Jede Anweisung endet mit einem Semikolon (;) – wie im Kommentar der Datei steht: „am Ende immer ;“. Vergisst du es, gibt PHP einen Parse Error!
✏️ Deine Aufgabe: Erstelle eine Datei 01_first.php und gib deinen eigenen Namen mit echo aus – einmal normal und einmal fett.

PHP lebt mitten im HTML: Überall, wo dynamischer Inhalt gebraucht wird, öffnest du kurz den PHP-Block, gibst etwas aus – und der Browser bekommt fertiges HTML.

02_html.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML & PHP</title>
</head>
<body>
    <h1><?php echo "Hallo DU"; ?></h1>
    <p><?php echo "Mein Inhalt kommt aus PHP"; ?></p>
</body>
</html>

🔍 Was du hier lernst

  • <?php ... ?> kann beliebig oft mitten im HTML geöffnet und geschlossen werden
  • Der Browser sieht nur das Ergebnis – im Seitenquelltext steht kein PHP mehr
  • Der statische Teil (<head>, Titel) bleibt völlig unberührt – PHP schreibt nur an seiner Stelle ins HTML
Merke dir: Der Server ersetzt die PHP-Blöcke durch ihre Ausgabe – dann erst wird die Seite an den Browser geschickt.
✏️ Deine Aufgabe: Baue eine eigene Seite 02_html.php mit Überschrift und Absatz, deren Inhalte per echo kommen.

Variablen speichern Werte, die du später wieder verwenden oder verändern kannst. Jede Variable beginnt mit einem $-Zeichen.

03_variablen.php
<?php
// 03_variablen.php

// Variablen in PHP mit $
$variable = 4;

// Variablentypen
$zahl = 12; // integer
$zeichen = "Blabla"; // string
$komma = 4.5; // float
$wahrheitswert = true; // boolean

// Ausgabe mit Variablen
// Entweder direkt ins echo
echo "Die Variable zahl hat den Wert $zahl";
// Oder mit . (Punkt) verknuepfen
echo "<br>Die Variable zeichen hat den Wert ".$zeichen;

?>

🔍 Was du hier lernst

  • Die Datentypen: integer (ganze Zahl), string (Text), float (Kommazahl mit Punkt: 4.5!), boolean (true/false)
  • Zwei Wege der Ausgabe: die Variable direkt in den String einbetten ("Wert $zahl") oder mit Punkt verknüpfen ("Wert: ".$zeichen)
Merke dir: Kommazahlen schreibt man mit Punkt: $komma = 4.5; – nicht 4,5. Mit Komma gibt es eine Fehlermeldung!
✏️ Deine Aufgabe: Lege Variablen für deinen Namen und dein Alter an und gib einen schönen Begrüßungssatz aus – einmal eingebettet, einmal mit Punkt verknüpft.

Möchtest du etwas 10-mal wiederholen? Schreibst du 10 Zeilen? Nein – dafür gibt es die for-Schleife. Sie hat genau drei Parameter:

04_schleife.php
<?php
// 04_schleife.php

// FOR Schleife
// 1. Parameter: Startwert (wo beginnt die Schleife zu zaehlen?)
// 2. Parameter: Abbruchbedingung (wie weit zaehlt die Schleife?)
// 3. Parameter: Schrittweite (in welchen Schritten zaehlt die Schleife?)
for ($i=1; $i<=10; $i++) {
    echo "FOR Schleife... $i";
    echo "<br>";
}

?>

🔍 Die drei Parameter im Detail

  • Startwert: $i=1 – die Zählvariable beginnt bei 1
  • Abbruchbedingung: $i<=10 – läuft, solange $i kleiner oder gleich 10 ist
  • Schrittweite: $i++ – erhöht $i nach jedem Durchlauf um 1
Merke dir: $i++ ist die Kurzform von $i = $i + 1. Die Variable $i nennt man Iterator oder Zählvariable.
✏️ Deine Aufgabe: Schreibe eine Schleife, die von 1 bis 20 zählt. Tipp: Nur die Abbruchbedingung ändern!

Lern-Beispiel aus dem Unterricht (abfrage-schleife.php): 26 Blöcke mit Überschrift und Text – und nach jedem zweiten Block soll ein zusätzliches <hr> ausgegeben werden. Dafür kombinieren wir erstmals Schleife + Abfrage – und lernen dabei den Modulo-Operator kennen.

abfrage-schleife.php – die flexible Variante
for ($i=1; $i<=26; $i++) {
    echo "<b>Überschrift vom Block $i</b>
    <br>
    <em>Ich bin ein Text vom Block</em>
    <hr>";

    // nach jedem zweiten Block ein <hr> zusätzlich ausgeben
    // Lösungsvariante 2 (eher flexibel)
    // Modulo (%-Zeichen) ergibt den Rest einer Division
    if ($i % 2 == 0) {
        echo "<hr>";
    }
}

Im Unterricht haben wir auch die Variante 1 besprochen: für jede gerade Zahl eine eigene if-Abfrage (if ($i==2) ... if ($i==4) ... if ($i==6) ...) – das funktioniert, ist aber „nicht sehr flexibel“: Bei 26 Blöcken bräuchtest du 13 Abfragen, und bei jeder Änderung der Blockzahl müsstest du alle anpassen.

Merke dir: $i % 2 ist der Modulo-Operator – er liefert den Rest der Division. Gerade Zahlen haben Rest 0, ungerade Rest 1. Mit einer einzigen if-Abfrage regelst du alle Fälle – dieselbe Technik wie bei den Quadratkarten und in Lektion 06!

Jetzt kombinieren wir alles: Die Schleife läuft auf dem Server und erzeugt HTML – aus 3 Zeilen PHP wird eine Liste mit 10 Einträgen!

05_htmlschleife.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Schleife</title>
</head>
<body>
    <h1>HTML Schleife</h1>
    <ul>
<?php
    for ($i=1; $i<=10; $i++) {
    echo "<li>Gäähhn...</li>";
    }

?>
    </ul>
</body>
</html>

🔍 Was hier passiert (Schritt für Schritt)

  • Der Browser lädt die Seite → der Server führt den PHP-Block zwischen <?php und ?> aus
  • Die Schleife läuft 10-mal und erzeugt jedes Mal ein <li>-Element
  • Der Browser erhält am Ende 10 fertige Listeneinträge – ohne dass wir 10 Zeilen tippen
  • Der PHP-Block darf direkt im HTML stehen, mitten zwischen <ul> und </ul> – Listeneinträge, die sich wiederholen, erzeugt die Schleife
Merke dir: Das ist das Grundprinzip dynamischer Webseiten: PHP erzeugt HTML – aus Daten, aus Berechnungen, aus Schleifen. Statt 10 Zeilen tippen: 3 Zeilen PHP!
✏️ Deine Aufgabe: Lasse die Schleife von 1 bis 15 laufen und schreibe in jeden Eintrag die Nummer: "<li>Punkt $i</li>".

Dein Programm soll entscheiden können – je nach Wert einer Variable. Dafür gibt es die Abfrage (auch Verzweigung genannt) mit if, else if und else.

06_abfrage.php
<?php
// 06_abfrage.php

$zahl = 5;

if ($zahl > 10) {
    echo "größer 10";
}
else if ($zahl == 10) {
    echo "gleich 10";
}
else {
    echo "kleiner 10";
}

?>

🔍 Was du hier lernst

  • PHP prüft die Bedingungen von oben nach unten – die erste wahre Bedingung gewinnt, der Rest wird übersprungen
  • Mit $zahl = 5: 5 > 10 ist falsch → weiter; 5 == 10 ist falsch → else greift: Ausgabe „kleiner 10“
  • == prüft auf Gleichheit – else ist der Notausgang, wenn keine Bedingung stimmt
Merke dir: == (zwei Gleichheitszeichen) vergleicht, = (eines) weist zu! $zahl == 10 ist eine Frage, $zahl = 10 ein Befehl – Die zwei zu verwechseln, ist ein klassischer Anfängerfehler.
✏️ Deine Aufgabe: Schreibe eine Noten-Abfrage: Bei einer Variable $note soll „Sehr gut“ (1), „Gut“ (2), „Bestanden“ (3–4) oder „Nicht bestanden“ (5–6) ausgegeben werden.

Jetzt wird es spannend: Die Benutzer:in gibt etwas ein – und dein PHP-Skript reagiert darauf. Das HTML-Formular schickt seine Daten an denselben Server, der sie in der Superglobalen $_POST ablegt.

07_formular.php
<form method="post">
    <input name="eingabe">
    <button type="submit">Schicksdu</button>
</form>

<?php

$eingabe = $_POST["eingabe"];
echo $eingabe;

?>

🔍 Was du hier lernst

  • Jedes <input> mit einem name-Attribut landet nach dem Klick auf „Schicksdu“ in $_POST["eingabe"]
  • method="post" im Formular legt fest: die Daten reisen unsichtbar im Request
  • Auslesen ist simpel: $eingabe = $_POST["eingabe"]; – und schon kannst du mit der Eingabe arbeiten
Achtung: Beim allersten Aufruf der Seite gibt es noch keine Formulardaten – PHP zeigt dann eine Warnung (Undefined array key). Wie man das sauber löst, lernst du in Lektion 09 mit isset().

Derselbe Ablauf wie in Lektion 07 – nur mit method="get". Der wichtigste Unterschied: Bei GET landen die Eingaben sichtbar in der URL.

08_formular_get.php
<!-- 08_formular_get.php -->

<form method="get">
    <input name="eingabe" placeholder="Gib was ein" required>
    <input name="alter" type="number" placeholder="Alter">
    <button type="submit">Schicksdu</button>
</form>

<?php

$eingabe = $_GET["eingabe"];
echo $eingabe;

$alter = $_GET["alter"];
echo "<br>Dein Alter: $alter";

?>

Nach dem Abschicken („Schicksdu“) sieht die Adressleiste so aus:

URL nach dem Abschicken
.../08_formular_get.php?eingabe=Hallo&alter=17

🔍 GET oder POST – wann was?

  • GET: Daten stehen in der URL – gut für Suchen und Filter, man kann die Seite verlinken und als Lesezeichen speichern. Nicht für Passwörter!
  • POST: Daten reisen unsichtbar im Request – gut für Passwörter und sensible Angaben
  • Neu hier: required erzwingt eine Eingabe im Browser, type="number" erzwingt eine Zahl – HTML-Validierung ganz ohne PHP
Merke dir: In der URL erkennst du GET-Formulare am Fragezeichen: alles dahinter sind Name-Wert-Paare, getrennt durch &. Ruf die URL doch mal direkt mit eigenen Werten auf – ganz ohne Formular!
✏️ Deine Aufgabe: Überlege: Warum darf das Login-Formular einer Bank nicht mit GET funktionieren? Wie sähe die URL aus – und wer könnte sie lesen?

Jetzt bauen wir alles zusammen: ein vollständiges HTML-Dokument mit Formular – und eine saubere Prüfung, ob überhaupt etwas gesendet wurde. Dafür sorgt isset(). Das ist die Lösung für das Warnungs-Problem aus Lektion 07!

09_formular-html.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Formular mit HTML</title>
</head>
<body>
    <h1>E-Mail check</h1>
    <form method="post">
        <input name="email" type="email" placeholder="E-Mail">
        <button type="submit">Überprüfen</button>
    </form>
    <p>
    <?php
        if ( isset($_POST["email"]) ) {
            $email = $_POST["email"];
            echo "Deine E-Mail $email ist gueltig";
        }
    ?>
    </p>
</body>
</html>

🔍 Was du hier lernst

  • isset($_POST["email"]) prüft: Existiert dieses Feld – wurde es also abgeschickt? So verschwindet die Warnung vom ersten Seitenaufruf
  • type="email" lässt den Browser selbst prüfen, ob eine gültige E-Mail-Adresse eingegeben wurde
  • Die Ausgabe steht genau dort im HTML, wo der PHP-Block ist – hier im <p>-Element
Merke dir: Das ist das professionelle Muster für fast jede Formular-Seite: Formular oben, if (isset(...)) darunter – erst prüfen, dann verarbeiten.
✏️ Deine Aufgabe: Baue einen „Login-Check“: Felder für Benutzername und Passwort (POST!). Mit isset() prüfst du, ob beide abgeschickt wurden – wenn ja: „Willkommen!“

Ein echtes Formular hat mehr als ein Textfeld: Radio-Buttons für Auswahlmöglichkeiten – und nach dem Abschicken bleiben die Eingaben dank PHP-Prefill erhalten.

10_formular-prefill.php
<?php
// 10_formular-prefill.php

if ($_POST) { // <- prüft, ob ein Formular abgeschickt ist
    $eingabe = $_POST["eingabe"];
    echo "Deine Eingabe: $eingabe";

    $hobby = $_POST["hobby"];
    echo "<br>Dein Hobby: $hobby";
}
?>

<form method="post">
    <input name="eingabe" placeholder="Gib was ein" value="<?php echo $eingabe;?>">

    <input type="radio" name="hobby" value="Reiten">Reiten
    <input type="radio" name="hobby" value="Turnen">Turnen

    <button>Abschicken</button>
</form>

🔍 Was du hier lernst

  • if ($_POST) ist die Kurzform von „wurde irgendwas per POST geschickt?“ – wie isset() in Lektion 09, nur kürzer
  • Prefill: value="<?php echo $eingabe;?>" schreibt die alte Eingabe zurück ins Feld – der Name bleibt nach dem Abschicken stehen
  • Radio-Buttons mit gleichem name bilden eine Gruppe – nur eine Option wählbar, ihr value landet in $_POST["hobby"]
Merke dir: Das name-Attribut entscheidet alles: gleiches name = gleiche Gruppe (Radio), und unter genau diesem name findest du den Wert in $_POST.
✏️ Deine Aufgabe: Ergänze eine eigene Radio-Gruppe (z. B. Lieblingsfach) und fülle das Textfeld nach dem Abschicken wieder vor.

Mit rand() erzeugt PHP Zufallszahlen – die Basis für Spiele, Zufallsbilder und Überraschungen auf der Webseite.

11_zufallszahlen.php
<?php
// 11_zufallszahlen.php

// Zufallszahlen in PHP mit rand(MIN, MAX)

$zuza1 = rand();
echo "Zufallszahl1: $zuza1";
echo "<br>";

$zuza2 = rand(1, 100);
echo "Zufallszahl2: $zuza2";

?>

🔍 Was du hier lernst

  • rand() ohne Parameter: eine große, beliebige Zufallszahl
  • rand(1, 100): eine Zufallszahl zwischen 1 und 100 (beide Grenzen sind erlaubt)
  • Bei jedem Seitenaufruf kommt eine neue Zahl – genau so funktioniert das Zahlenraten in UE_04 weiter unten!
Merke dir: rand(MIN, MAX) liefert eine ganze Zufallszahl inklusive beider Grenzen – ein Würfel wäre rand(1, 6).
✏️ Deine Aufgabe: Simuliere einen Würfel: Gib bei jedem Aufruf eine zufällige Zahl von 1 bis 6 aus.

Bis jetzt hat jedes Formular seine Daten an sich selbst geschickt. Jetzt machen wir es wie die Profis: zwei Dateien – eine HTML-Seite mit dem Formular und eine eigene PHP-Seite, die die Daten auswertet. Dafür sorgt das action-Attribut. Beide Dateien liegen bei uns im Ordner 12_formular-action.

12_formular-action/action_eingabe.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Formular Eingabe</title>
</head>
<body>
    <form method="POST" action="action_auswertung.php">
        <input name="eingabe" placeholder="Gib was ein">
        <button>Abschicken</button>
    </form>
</body>
</html>

Und so sieht die Auswertungsseite aus (action_auswertung.php) – ruf sie ruhig auch mal direkt im Browser auf:

12_formular-action/action_auswertung.php
<?php
// action_auswertung.php

// Die Formulardaten kommen aus action_eingabe.html

if ($_POST) { // <- gibt es ueberhaupt POST Formulardaten?
    $eingabe = $_POST["eingabe"];
    echo "Die Eingabe im Formular war: $eingabe";
}
else {
    echo "Keine Daten empfangen...<br>";
    echo "<a href='action_eingabe.html'>Zur Eingabe</a>";
}

?>

🔍 Was du hier lernst

  • action="action_auswertung.php": Das Formular schickt seine Daten an eine andere Datei – die Eingabeseite bleibt dabei unverändert stehen
  • Die PHP-Seite kann alleine aufgerufen werden (z. B. per Link) – deshalb der if ($_POST)-Check mit dem else-Zweig
  • Der else-Zweig ist der freundliche Plan B: „Keine Daten empfangen...“ plus ein Link zurück zur Eingabe – keine Fehlermeldung, kein toter Endpunkt
  • Wird das Formular abgeschickt, liegen alle Daten (wie gewohnt) in $_POST["eingabe"]
Merke dir: Mit action trennst du Eingabe und Auswertung in zwei Dateien – genau so baust du in UE_06 (Umfrage mit Bestätigungsseite) dein Umfrageformular und in der Rabatt-Übung weiter unten.
✏️ Deine Aufgabe: Erweitere action_eingabe.html um ein zweites Feld (z. B. „Alter“) und gib auf der Auswertungsseite einen schönen Satz mit beiden Angaben aus.

for ($discount = 5; $discount <= $maxDiscount; $discount += 5) {
